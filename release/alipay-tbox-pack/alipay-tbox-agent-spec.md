# 支付宝百宝箱（Tbox）智能体上线与 AI 订阅付费（Agent Pay）实操规范

> 【个性化依据：使用你已备案的杭州数创引擎营业执照与支付宝商户号直接开通，无需额外主体。】

## 一、智能体基础定位（精准命中支付宝“小微企业/办公刚需”高转化心智）
- **智能体名称**：标书排雷王 · 开标前废标自检
- **一句话简介**：30 秒穿透 Word 标书页眉页脚与报价表，精准核对人民币大小写差额、旧项目串名、工期冲突与 ★ 实质性条款漏项。
- **核心底座模型**：选择百宝箱免费内置 DeepSeek / 通义千问（零额外 Token API 费用）。

## 二、两种接入方式（二选一，推荐 MCP）
1. **方式 A：接入远程 MCP Server（推荐，免配字段）**
   - 直接在百宝箱「技能 / MCP 工具」填入同目录 `mcp-config-tbox.json` 中的 Cloudflare Worker `/mcp` 公网 HTTPS 地址。
   - 暴露工具：`audit_bid_document`（带 `readOnlyHint: true`, `destructiveHint: false` 安全标注，轻松过审）。
2. **方式 B：导入自定义 OpenAPI 插件**
   - 在百宝箱「插件 → 创建插件 → OpenAPI 导入」粘贴同目录 `openapi-tbox.json`。

## 三、支付宝官方「AI 订阅付费」收费结构（实盘梯度）
在支付宝开放平台申请「智能化场景受限密钥」后，在百宝箱商业化配置中创建 2 个订阅套餐计划（`plan_id`）：
1. **单次救急排雷包（¥9.9 / 次）**：适合临时赶标、开标前一晚核对的投标员（冲动消费主打 SKU）。
2. **投标部包月畅查卡（¥39.9 / 月，限 60 次/月防羊毛党）**：适合高频投标的工程/政企/软件集成商。

### 工作流三接口闭环顺序
1. 用户提交标书 → 先调用 `query-alipay-subscription-status`（查询 `uuid` 会员/剩余次数状态）。
2. **无次数/非会员**：先免费执行一次 `audit_bid_document`（`paid_order_verified: false`），展示**安全健康分 + 总雷数 + 前 2 处精确定位**，让用户亲眼看到标书确实藏着废标雷（建立沉没成本与紧迫感）！随即调用 `initialize-alipay-subscription-order` 生成 ¥9.9 / ¥39.9 支付宝收银台支付链接。
3. **有次数/支付回调成功**：调用 `times-alipay-subscription-consume` 核销 1 次额度 → 再调用 `audit_bid_document`（`paid_order_verified: true` + 隐式 `X-Plugin-Secret`）输出全部废标定位与《开标前逐项清零核对单》。

## 四、百宝箱过审与售后免责清单
- 明确标注**非法律/造价鉴证服务**：仅提供招投标文件形式合规与数值交叉自检辅助，最终以招标文件原件为准。
- 明确承诺**标书零留存**：纯内存即时解析，响应结束立即销毁，不落盘、不用于模型训练。
- 明确退款边界：若因非标准 `.docx` 损坏导致解析失败，不扣减次数（未进入核销节点）。
